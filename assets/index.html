Feature Reality

The Old Manual Way vs. The Enlighten Engine

Why community developers and AI engineers are switching to Enlighten.

✕

The Fragmented Setup

  • ❌
    Ghost Folder Pollution: Creates .codex, .zed, and .claude folders even if you only use Antigravity.
  • ❌
    Fails on Raw CLI Repos: If a GitHub repo lacks a pre-authored SKILL.md, traditional tools refuse to install it.
  • ❌
    Strict Exact-Word Search: A minor typo like ponlytail returns 0 results and halts your agent flow.
  • ❌
    Messy Removal: Leaves broken symlinks and orphaned binaries strewn across global paths.
✓

The Enlighten Engine

  • ✨
    Active-Agent Scoping: Installs strictly into the calling agent's harness + global fallback. Never creates ghost folders.
  • ✨
    Auto-Skill Synthesis: Detects raw CLI binaries (like ripgrep or lazygit) and generates intelligent wrapper skills automatically.
  • ✨
    Fuzzy Typo Discovery: Built-in Levenshtein engine matches misspellings and indexes local installed skills offline.
  • ✨
    Atomic Uninstaller: enlighten uninstall cleanly removes registrations, symlinks, and binaries in one go.
Core Architecture

Engineered for Autonomous Reliability

Every feature was designed to keep your agents focused and your filesystems clean.

🎯

Active-Agent Scoping

Detects whether you're running Gemini, Claude, Hermes, or Cursor, and isolates modifications to that harness only.

📖

README-First Execution

Parses installation instructions written by repository authors before falling back to generic git clones.

🔍

Typo-Tolerant Finder

Search community registries and local directories with fuzzy keyword matching so queries never hit dead ends.

Zero-Config Tool Synthesis

Atomic Clean Uninstaller

Single-command removal untangles registrations, cleans lockfiles, and restores your agent environment.

⚡

Offline Cache Engine

Local lockfiles and cache indexes allow discovery and verification without hanging on slow network requests.
