Three steps, zero manual configuration

Enlighten reads what repository authors specify instead of running slow, blind clones.

README check first

Fetches the repository guide over HTTP in milliseconds. Discovers author-specified installation instructions before downloading commits.

Official guide steps

Executes the author’s official commands (Skills CLI, curl one-liner, or package managers) directly as built and intended.

Global skill sync

Registers newly installed skills across all agent harnesses automatically. Any tool downloaded is ready in all environments.

Supported agent environments

Quick start commands

Install Enlighten once, then use it from your shell or inside agent chat.

curl -fsSL https://.../install.sh | bash One-command universal curl installer
npx skills add Ayan-Jain-737/enlighten-agent-tool -g -y Install via Skills CLI
enlighten install <repo-url> Install repository and register skills globally
enlighten diagnose <repo-url> Analyze repository guide without installing
enlighten list-installed Show all managed installations and skills
enlighten uninstall <id> --force Safely remove repository and unregister skills
