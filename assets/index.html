Enlighten

Universal GitHub repository installer for AI agent harnesses

⚡ Auto-Detect

Intelligent scanning detects language and framework automatically

🔧 Multi-Platform

Works with Claude Code, Hermes, Opencode, and more

🧼 Clean Uninstall

Fully reversible installations with no traces left behind

Quick Commands

enlighten install <repo-url> Install any GitHub repository
enlighten list-installed View all managed installations
enlighten diagnose <repo-url> Analyze repository without installing
