Install AI agent tools instantly

Universal GitHub repository installer for Claude Code, Hermes, Opencode, Codex and more.

Install on npm 
$ enlighten install https://github.com/vercel/next.js
> Scanning repository...
  Language: TypeScript
  Framework: Next.js
  Profile: web-developer
  Harness: Hermes
Install complete!

Key features

Auto-Detect

Intelligent scanning detects language and framework automatically.

Multi-Platform

Works with Claude Code, Hermes, Opencode, Codex and more.

Clean Uninstall

Fully reversible installations with no traces left behind.

Quick commands

enlighten install <repo-url>    Install a GitHub repository
enlighten diagnose <repo-url>  Analyze repository without installing
enlighten list-installed        View all managed installations
enlighten uninstall <id>        Remove an installed repository
