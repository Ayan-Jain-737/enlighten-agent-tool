Engineered for real agent autonomy

Enlighten bridges the gap between static prompt skills and executable developer software.

Universal Discovery

Search open skills.sh packages, curated battle-tested capabilities, and local installed skills in real time. Resilient with offline fallback catalogs.

README-First Engine

Fetches the repository guide over HTTP in milliseconds. Executes the author’s recommended installation steps before attempting heavy clones.

Automatic Skill Synthesis

99% of GitHub repos don't have a SKILL.md. Enlighten inspects entry points and synthesizes a full agent skill wrapper automatically.

Real Code Compilation

Builds Rust, Go, Python, and Node projects. Symlinks executables directly into ~/.local/bin/ so agents can run tools immediately.

Active Agent Scoping

Clean filesystem discipline. If you use Antigravity / Gemini, skills install only in .gemini and global storage—never creating ghost folders for Codex or Zed.

Agent-Native JSON API

Pass --json to any command (find, install, diagnose, list) for clean, machine-readable data designed for AI agent tool calling.

Quick start commands

Install Enlighten once, then use it from your shell or inside agent chat.

enlighten find <query> Discover skills, packages, and CLI tool repos (e.g. enlighten find react)
enlighten install <repo-url> Install repository, compile code, and register skills for active agent
enlighten install <repo> --agent gemini Explicitly target an agent harness (e.g. gemini, claude, codex)
enlighten diagnose <repo-url> Analyze repository guide and tech stack without installing
enlighten list-installed Show all managed installations, binaries, and skills
enlighten uninstall <id> --force Safely remove repository, unregister skills, and unlink binaries
